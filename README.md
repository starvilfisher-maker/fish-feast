# 大鱼吃小鱼 v1.2 · 海底成长记

原生 HTML、CSS、Canvas 和 JavaScript 的单人 / 同屏双人游玩小游戏，无外部运行依赖。

[公开游玩](https://starvilfisher-maker.github.io/fish-feast/) · [版本更新记录](CHANGELOG.md)

v1.2：取消大鱼蓄力冲锋，增加手机方向键与冲刺按钮，适配竖屏、横屏及全屏游玩。开局仍有大鱼与巨鲨，先寻找安全路线，再捕食小鱼成长。

## 运行

在本目录运行 `node server.mjs`（或 `npm start`），然后打开 http://127.0.0.1:4173 。也可以直接打开 `docs/index.html`。

## 公开发布到 GitHub Pages

将本目录内容上传到公开仓库的 `main` 分支，保留 `docs` 文件夹。

在仓库的 **Settings → Pages → Build and deployment** 中，选择 **Deploy from a branch**，将分支设为 **main**、文件夹设为 **/docs**，点击 **Save**。

部署完成后，Pages 页面会显示公开游玩链接。以后更新 `main` 分支中的 `docs` 文件，GitHub Pages 会重新发布游戏。

发布方式参考 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 检查

运行 `node check-all.mjs`（或 `npm run check`）检查玩法、双人独立状态、护盾、交互和长期运行稳定性。检查记录见 `QA.md`。

## 玩法

- 鼠标移动、方向键或 WASD 控制金色小鱼；手机可按住上下左右按钮，也可拖动游戏区域。方向和冲刺支持同时触控；松手、取消触控、旋转屏幕或暂停都会清除按住状态。
- 手机竖屏时按钮位于游戏区下方，横屏时方向键在左、冲刺在右。点击“横屏游玩”扩大游戏区域，并在浏览器支持时进入全屏、锁定横屏；不支持自动旋转时手动将手机横过来，点击“退出全屏”返回。
- 根据相对体型判断能否吃掉，河豚鼓起保留文字预警，只有护盾生效时显示蓝色光圈，挡伤或8秒到期后消失。
- 开始前可选择单人冒险或双人游玩。同一键盘：1P金色，WASD移动、空格冲刺；2P蓝色，方向键移动、Shift冲刺。鼠标和触控仍可控制1P。双人各自得分、升级、生命、护盾及连吃，各自的三条生命耗尽则独立出局，达到10级独立通关；另一人继续，直到两人都完成或出局再分别结算。玩家之间不会互相吃掉或受伤。
- 共享鱼、特殊生物和道具只会被最近的符合条件的玩家领取一次，通关或出局玩家停止移动，不再领取食物/道具、吸引捕食者或受伤；出局和通关结果不改变另一人的生命或成长。暂停与重开同时作用于两名玩家。
- 三条生命，途中无法补充，也不能复活；受伤后短暂无敌；累积 1900 分达到 10 级获胜。升级门槛为 32、88、180、312、480、710、1010、1400、1900 分；前六级保留较慢节奏，每次吃鱼都会逐渐变大。
- 小丑鱼、蝶鱼、河豚、狮子鱼、神仙鱼与锤头鲨等共11种鱼类。所有固定体型从开局起都可刷新，最大鲨鱼体型160，玩家最大体型180。平时约30%小鱼、30%中型鱼、40%大鱼或巨鲨；桌面最多同时两条巨鲨，小屏最多一条，达到上限改刷普通大鱼。双人游玩适合同屏键盘；手机画面按比例缩放体型，碰撞和绘制保持一致。
- 稀有的星光水母、金色海马都可以吃，不受体型限制。水母奖励当前等级成长目标的 65%（向上取整），海马奖励 100%。
- 首只特殊生物在开局 25 秒后出现，之后间隔 35–50 秒；同时最多一只。水母与海马和普通鱼一样从画面一侧游入，从另一侧游出，不折返或追逐玩家。海马速度更快。
- 难度随等级与存活时间上升：鱼游得更快、刷新更频繁，鱼群体型分布保持固定；猎食潮时大鱼或巨鲨占比提高到约57%。鲨鱼和灯笼鱼保持正常游速，轻微跟随前方玩家，不再蓄力或冲锋。小鱼会躲闪；河豚每10秒鼓起2.7秒，鼓起时碰到就受伤；狮子鱼刺伤会减速2秒。
- 空格、Shift或冲刺按钮：0.7秒加速，冷却6秒；3秒内继续吃普通鱼可延续连吃，每5连吃刷新冲刺，不额外增加成长分数。
- 护盾道具提供8秒内的一次伤害抵挡；只有护盾道具，不生成加生命道具。首个道具18秒出现，之后间隔26–38秒。所有效果和刷新计时都随暂停冻结，重开时清空。
- 每45秒触发持续10秒的海底事件：急流会让玩家漂移、鱼游得更快；每第三次事件是捕食者更多的猎食潮。
- P / Esc 暂停或继续，R 重新开始；右上角切换音效。
